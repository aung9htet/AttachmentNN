# TCDS paper (draft)

Draft of the journal paper for *IEEE Transactions on Cognitive and Developmental Systems*,
built on the experiments in this repository. The Living Machines 2024 paper is cited as
support; the npj Robotics draft provides the coupled-model analysis the new paper is compared
against (both in `papers/`).

**Start with `paper_planning.md`.** It is the master planning document: storyline, section-by-section
blueprint, vocabulary, full technical record, every number with its source, and a map of all
references. The draft is written from it.

| Path | Content |
|---|---|
| `paper_planning.md` | Master planning document (supersedes the narrative outline) |
| `draft/main.pdf` | The paper (IEEEtran journal format). TCDS charges for every page beyond 10 (references and biographies included), so it must end by page 10; `make_overleaf_zip.sh` checks this and the 150-250-word abstract |
| `draft/supplement.pdf`, `draft/supplement.tex` | Supplementary material (Sections S1-S6, Figs. S1-S10, Tables S1-S4), not counted in the page limit |
| `draft/main.tex`, `draft/refs.bib` | Sources. `refs.bib` holds only references from the LM and npj reference lists. `\draftmarkerstrue`/`\draftmarkersfalse` at the top of `main.tex` and `supplement.tex` switches between the working draft and the submission version |
| `draft/figures/` | Figures, generated by `analysis/tcds/figures.py` (plots) and `draft/diagrams/build.sh` (Figs. 1-2) |
| `draft/diagrams/` | TikZ sources of the concept (Fig. 1) and architecture (Fig. 2) diagrams |
| `draft/tables/` | Tables, generated by `analysis/tcds/paper_numbers.py` |
| `draft/overleaf_import/paper_draft_ver_{N}.zip` | Numbered Overleaf packages of the draft (upload as a new project; pdfLaTeX, `main.tex`). Each run of `papers/tcds/make_overleaf_zip.sh` adds the next version after checking that the zip compiles on its own |
| `narrative/narrative_outline.pdf` | Earlier narrative outline, kept for reference; superseded by `paper_planning.md` |

Draft markers in the PDF:

- red `[CITE: ...]`: a claim that needs a source outside the LM/npj reference lists. The text
  describes the kind of source needed; the full list is in the last appendix.
- blue `[Authors: ...]`: a point to check before submission.
- grey biographies and photo frames: placeholders that reserve the space of the final ones, so that the
  page count of the draft matches the final paper.

Build the draft and the Overleaf package (TeX Live, or the `texlive/texlive` Docker image):

```bash
cd papers/tcds/draft && pdflatex main && bibtex main && pdflatex main && pdflatex main
pdflatex supplement && bibtex supplement && pdflatex supplement && pdflatex supplement
docker run --rm --user "$(id -u):$(id -g)" -e HOME=/tmp -v "$PWD:/w" -w /w \
    texlive/texlive:latest papers/tcds/make_overleaf_zip.sh      # from the repository root
```

Regenerate the analyses, figures and tables (NumPy, SciPy, Matplotlib, scikit-learn; the network
weights are read without PyTorch; the MiRo Docker image's Python at `/workspace/.venv/bin/python` has
everything). Run from `analysis/tcds`, in this order:

```bash
python3 check_runs.py       # validate every Gazebo run against its controller -> results/run_checks.csv
python3 gazebo.py           # per-run measures -> results/gazebo_runs.csv
python3 robustness.py       # offline strips, plane, stability, network and notebook ablations
python3 estimator_eval.py   # learned coupling in the agent simulator
python3 inverse.py          # kinematic stand-in runs and the inverse problem
python3 paper_numbers.py    # results/numbers.json, tables -> papers/tcds/draft/tables
python3 figures.py          # figures -> papers/tcds/draft/figures
```
